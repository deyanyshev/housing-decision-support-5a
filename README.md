## Постановка задачи по РПД

В файле не указано отдельной формулировки цели для 5А. Из условий варианта следует цель — выбрать жильё по цене, району и транспортной доступности и рассчитать ипотечные переплаты.

- «Сбор данных (Циан API): цена/район/транспортная доступность».
- «Применение метода AHP (Analytic Hierarchy Process) для выбора».
- «Расчет ипотеки (аннуитет vs дифференцированный)».
- Выход — «Ранжированный список объектов с расчётом переплат».

Три метода из перечня вопросов к зачёту:

1. **Метод Саати (AHP), № 29 и 83.** Рассчитываем веса цены, района и доступности метро из главного собственного вектора взаимно обратной матрицы. Проверяем `CR = CI / RI`, где `CI = (λmax − 3) / 2`. При `CR > 0,10` расчёт останавливается.
2. **TOPSIS, № 74.** Нормируем числовые критерии по евклидовой норме столбца, применяем веса AHP и ранжируем все объекты по близости к идеальному решению. Цена и время до метро минимизируются, оценка района максимизируется.
3. **Множество Парето, № 15.** Отмечаем объекты, для которых в выборке нет варианта одновременно не дороже и не дальше от метро, с хотя бы одним строгим улучшением. Это проверка компромисса по двум критериям. Итоговый рейтинг сохраняет все объекты и учитывает также район.

Анализ чувствительности предусмотрен в перечне вопросов, № 98. Проверяем, как меняется рейтинг при умножении веса цены на 0,8 и 1,2 с последующей нормировкой всех весов (не из файла, по практике).

## Запуск

Проверено на Python 3.12. Из папки проекта (не из файла, по практике):

```text
python -m pip install -r requirements.txt
python -m src.run_analysis
```

По умолчанию анализ заново создаёт `data/housing.csv` с seed `20261112` и перезаписывает результаты. Отдельная генерация: `python -m src.data`. Для согласованной внешней выгрузки: `python -m src.run_analysis --csv путь_к_файлу.csv`. Нужны все столбцы выше и оценка каждого района во входных настройках. Для нового учебного набора можно указать `--seed` вместо `--csv`. Данные из внешнего файла сохраняют их входную отметку источника.
